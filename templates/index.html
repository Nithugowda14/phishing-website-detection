Cybersecurity Awareness

How to Stay Safe from Phishing Attacks

Essential security practices to safeguard personal credentials and sensitive data.

Verify HTTPS & Certificate

Always inspect the padlock icon in the browser address bar. Legitimate organizations secure their web traffic using valid SSL/TLS certificates.

Inspect Domain Spellings

Watch for typosquatting tricks such as paypa1.com or rnicrosoft.com. Phishers register visually identical lookalikes.

Beware of IP Addresses

Legitimate public portals never ask you to authenticate on raw numeric IP addresses like http://192.168.1.1/login.

Ignore Artificial Urgency

Phishing campaigns frequently use frightening messages ("Account Suspended within 24 hours!") to manipulate victims into hasty decisions.

Unmask Shortened Links

Avoid entering sensitive credentials after clicking links shortened with services like bit.ly, which obscure the genuine destination.

Enable Multi-Factor Auth (MFA)

Even if an attacker captures your password via a counterfeit site, strong MFA prevents unauthorized account compromise.
